7za.exe: unmodified x64 7-Zip 21.07 standalone console utility, Copyright 1999-2021 Igor Pavlov.
Bundled from npm 7zip-bin 5.2.0: https://github.com/develar/7zip-bin
7-Zip source for this version: https://github.com/ip7z/7zip/tree/21.07
Source archive: https://github.com/ip7z/7zip/archive/refs/tags/21.07.zip
Licenses: 7zip-LICENSE.txt, LGPL-2.1.txt, 7zip-bin-LICENSE.txt.
7-Zip is a separate subprocess for local ZIP/7Z decompression; no changes were made to it.

The user-supplied VPK GUI tool is not bundled or executed. The skin assets and tutorial are test inputs and are not included in this application.

7z.exe and 7z.dll: unmodified x64 7-Zip 26.04 full console extractor, Copyright 1999-2026 Igor Pavlov.
Official binary origin: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-x64.exe
Extracted files only; the installer was never run.
7-Zip source for this version: https://github.com/ip7z/7zip/tree/26.04
Source archive: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-src.7z
License: 7zip-full-LICENSE.txt (GNU LGPL 2.1 plus unRAR restriction for RAR decoder code).
Used as a separate subprocess to inspect and decompress supported local archives including RAR.
The older standalone 7za.exe is retained as a fallback; it cannot decode RAR.
