[English](README.md) · **简体中文**

**北极星双服切换，DDS、VTF 与 Mod 自动安装，一个启动器就够。**

## 安装与首次使用

TFX 是 **Windows x64 便携式启动器**。需要已购买并安装的 TITANFALL 2、可以正常使用的 Steam / EA 环境，以及足够存放客户端、安装暂存与恢复数据的空间。启动器不包含游戏本体。

1. 在 [Releases](https://github.com/harrycaoguitar/TFX_Launcher_forNorthStar/releases/latest) 下载并运行 `TFX-Launcher-1.0.4.exe`。
2. 等待自动检测游戏；检测失败时，选择包含 `Titanfall2.exe` 的游戏根目录。不要选 `steamapps`、`common` 或 Mod 子目录。
3. 打开**北极星**，选择**中国服**或**全球服**；如果提示未安装，先安装对应客户端。
4. 点击启动。Steam / EA 若要求登录或确认，请在对应平台完成。
5. 安装内容时，打开**皮肤安装**，将一个包或文件夹拖到左侧。TFX 会立即显示接收的名称，识别实际内容，检查通过后自动安装。

具体实测范围请查看对应版本发布时的验收说明。外部服务、第三方包和不同游戏安装的情况可能与演示或测试环境不同。

## Northstar 与 NorthstarCN 双服启动

TFX 分别记录两种客户端的实际安装状态，下载缓存不等于已经安装。内置的首次安装数据为 **NorthstarCN 1.17.7** 与 **Northstar 1.31.13**；联网游戏仍然需要网络连接。

两种客户端准备完成后，切换复用对应的核心文件，无需每次重新解压整包，个人 Mod 与皮肤资源继续保留。能够识别的较新本地客户端会被保留，不会直接被较旧的内置版本覆盖。启动页显示当前所选客户端的实际版本与状态。

- **安装与修复：** 每个区域都有独立的安装状态与操作。先安装，再启动。
- **客户端更新：** 按所选区域检查客户端发布、刷新版本或在设置中重新安装。客户端更新与 TFX 本身更新分别管理。
- **启动反馈：** 检查游戏进程和 Northstar 菜单加载；失败、平台交接或启动后立即退出时，会结束等待并显示反馈。
- **运行保护：** 游戏运行期间限制客户端替换与皮肤写入；目标目录或配置发生变化时，在错误位置提交前停止操作。
- **减少游戏时占用：** “游戏启动后退出 TFX”默认关闭。开启后，确认启动成功才退出；失败时保留启动器显示结果。

**原版**入口保留战役与官方多人游戏，通过正常的 Steam / EA 环境启动。

### 官服 Mod 启动与三服独立

**已包含于正式版 1.0.4。** 在**原版**启动界面选择**不带 Mod**或**带 Mod**，交互方式与北极星的中国服 / 全球服选择一致。**不带 Mod**通过正常的 Steam / EA 环境启动；**带 Mod**加载兼容的客户端 Mod，并保留官方多人游戏，不会因此连接到北极星社区服。

第一次使用**带 Mod**前，需要通过页面的安装按钮准备 **VanillaPlus 2.5.1** 与 **Northstar 全球服加载组件 1.29.0 或更新版本**。组件缺失、损坏或过旧时会提示安装或修复，单纯查看状态不会自动下载，也不会启动游戏。安装流程校验内置 VanillaPlus 文件，准备全球服加载组件并展示进度；安装与修复期间需保持游戏关闭。TFX 会根据启动模式启用对应的必要组件，切回北极星时恢复社区服菜单。

官服带 Mod 模式保留正版游戏的 Steam / EA 启动身份。严格匹配到所选游戏的 Steam 安装时，TFX 通过 Steam 传递受控的游戏参数；其他安装使用 `Titanfall2.exe`。启动器仍会等待新的游戏进程，并确认 VanillaPlus 到达主菜单。如果平台要求确认启动，请在 Steam / EA 中完成。

VanillaPlus 适用于**与官服兼容的客户端 Mod**，并不代表所有北极星 Mod 都能在官服使用。依赖自定义服务器、修改服务端玩法或要求北极星专用服务的 Mod 可能无法正常工作，请先核对各 Mod 的兼容范围。框架作者、来源与许可见[第三方说明](THIRD_PARTY_NOTICES.md)。

1.0.4 的**偏好设置 → 三服模组独立**取代双服设置，**默认关闭**。开启后，**官服、NorthstarCN 中国服、Northstar 全球服**分别记住 Mod 开关。首次开启时，三边以当前选择为基础；新添加的 Mod 只在当前区域默认启用，另外两边默认关闭。独立范围仅为 **Mod 的启用状态**，安装包文件、原生插件、DDS 与 VTF 皮肤继续共享，不会生成三份游戏，也不隔离插件代码。关闭时继续共用个人 Mod 开关，必要兼容组件仍随启动模式自动调整。

选择**不带 Mod**时，TFX 会临时阻止已识别的北极星代理自动加载，并中和 `run_northstar.txt` 标记，在启动交接完成或启动失败后恢复原文件。中断恢复记录用于保留原始状态；发现其他程序修改时不会强行覆盖。该选择控制通过加载器运行的 Mod，不会卸载共享的 DDS / VTF 皮肤。Steam / EA 中另外配置的启动参数也应与所选模式保持一致。

## 社区服务器列表

侧栏的**社区服务器**以纵向列表显示所选区域的公开目录。支持按服务器名、地图、模式搜索，可查看人数 / 容量、描述和所需 Mod，人数较多的服务器优先展示。列表使用与其他页面一致的滚动区域。

可手动刷新；相关页面可见时也会定期刷新，不需要时暂停轮询。请求不可用与缓存数据会分别标识。北极星启动页保留对应公开目录的人数汇总，该数值不代表整个网络的全部在线玩家。时间与刷新时间戳跟随电脑系统时钟。

此处用于浏览，进入游戏后仍通过对应客户端的服务器浏览器加入服务器。

## 我的模组、Thunderstore 与双服独立

**我的模组**使用卡片展示名称、作者、介绍与开关状态，可搜索上述字段。自绘排序菜单提供**添加时间、首字母、开关状态**三种方式。开关显示保存反馈，失败时恢复实际状态；列表更新保留搜索与滚动位置。支持批量操作，必需的核心组件会受到保护。

通过**我的模组 → 发现模组**浏览 [Thunderstore 北极星目录](https://thunderstore.io/c/northstar/)。支持搜索、分类、依赖规划、下载进度和取消。安装内容检查完成后才提交；失败时保留或恢复原有内容。包含原生插件的包会要求明确确认。各 Mod 的作者与许可信息保留。

本地导入也使用**皮肤安装**入口。带有有效 `mod.json` 的兼容压缩包或完整文件夹会被识别为 **Mod** 并自动安装，之后到**我的模组**管理开关与卸载。定义错误、危险路径、压缩包损坏和混合不兼容内容都会给出明确报错。

### 双服模组独立——已发布的 1.0.3

需要中国服与全球服使用不同 Mod 开关时，在**偏好设置**开启**双服模组独立**。该选项**默认关闭**。

- 第一次开启时，两边都从当前开关配置开始；之后只记住所选区域的修改。
- 切换区域时应用该区域已保存的开关状态。成功后才切换选择；失败时保留原区域。
- 在一边新添加的 Mod，默认只在当前区域启用，另一边关闭。
- 关闭独立功能后，以当前区域的开关作为两边共用状态。恢复默认设置会关闭此功能。

独立的是 **Mod 的启用状态**。已安装的包文件、原生插件二进制、DDS 和 VTF 皮肤仍然共享；这不等于两份游戏安装，也不会隔离插件代码。

## DDS、VTF 与 Mod 统一自动安装

在左侧拖入一个文件或文件夹，也可以用该区域的文件 / 文件夹选择按钮。左侧立即显示文件名称，TFX 按**实际内容**识别 DDS、VTF 或 Mod，检查后自动安装。右侧展示检查和进度，估算百分比带有 `≈`，只有实际返回成功后才达到 100%。完成后右下角弹出通知。

| 内容 | 兼容输入 | 需要保留的结构 |
|---|---|---|
| DDS 皮肤 | DDS 单文件、完整皮肤文件夹、可读取的 ZIP / 7z / RAR 等受支持压缩包 | 用于匹配游戏资源的 DDS 文件名 |
| VTF 皮肤 | 完整皮肤文件夹、可读取的 ZIP / 7z / RAR 等受支持压缩包 | 关联 materials / models 目录结构 |
| 北极星 Mod | 带有有效 `mod.json` 的完整 Mod 文件夹或可读取的受支持压缩包 | 模组定义与资源结构 |

VTF 单文件缺少完整的包结构，不能直接作为完整皮肤安装。压缩包能够读取仍需内容兼容，扩展名本身不能证明格式正确。一次导入一个包。导入被拒绝后清空待安装选择，防止误装上一个正确的文件包。

**DDS 检查**包括文件头、压缩格式、尺寸、资源匹配与分辨率覆盖。**VTF 检查**包括材质、模型资源与压缩包结构。同一武器 DDS → VTF 或 VTF → DDS 时统一处理原有资源，减少旧文字、瞄具与不兼容模型残留。能否安装取决于可识别的游戏资源与包内容。

### 缺失原版资源时的定向补全

TFX 优先使用已验证的原版缓存或可用备份。必要的原版资源缺失时，可通过修复流程将**仅需的原版资源**下载到独立缓存，再继续皮肤操作，不要求 Steam 验证整个游戏、覆盖其他已安装皮肤。

定向下载可能需要使用拥有 TITANFALL 2 的 Steam 账号登录。TFX 会在需要时显示说明和二维码流程，**不需要在 TFX 输入 Steam 密码**。下载辅助程序与 Steam 处理认证，TFX 不会将登录数据上传到作者的服务器或云端。辅助程序使用隔离的临时登录环境，正常进度日志不包含登录秘密信息；确认登录前请阅读 Steam 提示。

修复方案绑定已验证的本机游戏资源元数据。本地清单、所有权、网络或剩余空间不能确认时，会解释受阻步骤，不会凭猜测写入游戏文件。也可通过修复流程提供可信的原版资源备份。

## 武器库：选武器，选皮肤

**武器库**位于皮肤安装页面，包含 **40 把武器**，包括泰坦武器与泰坦近战武器。简体与繁体中文武器名、分类以游戏官方本地化为依据。武器卡片展示对应轮廓，可搜索武器和皮肤名。

DDS、VTF 与能够识别的 Mod 皮肤集中显示在对应武器下，资源路径是主要归属依据，不单凭压缩包名称判断。Mod 皮肤保留**管理 Mod**操作，开关与卸载仍在“我的模组”。

DDS / VTF 历史记录中，选中武器后点击任一有效关联记录的**使用此皮肤**即可。点击皮肤 **A 会恢复 A 安装后的状态**，而非 A 安装前的状态。TFX 自动处理必要的中间步骤，无需手动逐条恢复较新的记录；恢复后还可以再选其他有效历史目标。**恢复原版皮肤**用于返回该武器关联的原版状态。

当前目标标记为**正在使用**，有效历史标记为**可恢复**，检测到不可用的目标会禁用并解释原因。列表检查记录元数据与所需归档是否可用；还原写入前会完整校验恢复内容。右侧默认展示数量根据左侧武器网格的实际高度调整，点击**展开更多记录**查看其余内容。还原有确认、进度和成功通知。仅修改所选武器的 DDS / VTF 资源，其他武器保留；若启用的 Mod 覆盖同一武器，游戏里仍可能显示 Mod 皮肤，需要在“我的模组”关闭。

发现中断安装时，先使用**武器库内部**的恢复提示，再继续安装。该类恢复可能涉及这次操作关联的多把武器。安装与还原期间保持游戏关闭，并保留仍在使用的恢复数据。TFX 可清理已取消或已回滚、且没有活动恢复引用的废弃缓存，仍可恢复的历史目标会保留。

## 偏好设置、外观与语言

TFX 使用磨砂半透明面板、圆角卡片、短暂的页面过渡与动作反馈，并照顾系统减少动态效果的设置。拖动顶栏空白区域可以移动窗口；Windows 支持时使用圆角窗口。

十种配色为 **Aurora、Abyss、Nebula、Sakura、Ember、Grove、Sandstone、Graphite、Glacier、Mist**，后两种为浅色主题。五种语言为 **English、简体中文、繁體中文、Deutsch、Français**。首次打开跟随系统语言，中文系统默认中文，其他系统默认英语，手动保存的选择优先。语言与排序菜单均使用 TFX 自身的样式。

语言、主题预览等常规修改统一保存。存在未保存修改时离开设置，可选择**保存并离开、放弃并离开、继续编辑**；保存失败会保留输入。皮肤启动保护和双服模组独立等单独确认的开关在修改时保存。

| 分组 | 主要功能 |
|---|---|
| 外观与语言 | 五语言、十主题与预览 |
| 游戏启动 | 游戏目录、启动参数、启动后退出、双服 Mod 状态 |
| 皮肤启动保护 | 开关、查看或重新记录设置 |
| 客户端更新 | 自动检查、版本刷新、保留文件、重新安装所选客户端 |
| 网络连接 | DNS 缓存与明确执行的 DNS 设置 |
| 维护 | 清理安装缓存、进程控制、重启启动器 |
| 关于 | HarryCao、反馈链接、特别鸣谢、TFX 版本与更新检查 |

**皮肤启动保护**同时适用于 DDS 与 VTF，启动前恢复已记录的 `setting.stream_memory` 和 `setting.mat_picmip`。请先确认皮肤显示正常，再记录当前设置；它不是适用于所有皮肤的固定画质预设，不锁定游戏内选项，也不安装额外 UI Mod。

**恢复默认设置**需要持续长按，避免误触。它重置偏好设置，包括关闭双服模组独立，不会删除游戏、已安装皮肤或必要的恢复资源。

## 更新、存储与问题排查

TFX 本身通过[此 GitHub 仓库](https://github.com/harrycaoguitar/TFX_Launcher_forNorthStar/releases)检查更新。北极星客户端使用所选区域的发布来源，两者分别管理。

偏好设置保存在 Windows 应用数据目录。客户端与包缓存可能优先使用可用的 `D:/TFX-Launcher-Data`；预备客户端也会使用游戏目录的 `.tfx` 区域。DDS / VTF 缓存与恢复记录保存在受管理的应用数据位置。可用设置里的清理安装缓存移除可重新下载的内容，不要手动删除仍可能需要的皮肤恢复链。

| 情况 | 建议操作 |
|---|---|
| 找不到游戏 | 选择包含 `Titanfall2.exe` 的根目录。 |
| 所选区域未安装 | 安装该客户端，再启动。 |
| Steam / EA 打开但游戏未进 | 完成平台待确认提示，查看启动结果后再重试。 |
| 下载或服务器列表不可用 | 检查网络并刷新，注意缓存时间。 |
| 导入包被拒绝 | 查看内容报错，保留原有名称与结构，一次导入一个兼容包。 |
