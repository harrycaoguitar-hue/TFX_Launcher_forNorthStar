开始使用
运行 TFX-Launcher-1.0.0.exe。目录版运行 TFX-Launcher/TFX-Launcher.exe，并保留整个目录。
需要已安装的 TITANFALL 2 和正常可用的 Steam / EA 环境。启动器自动检查已保存目录、Steam 库与 EA 安装信息；无法识别时，手动选择包含 Titanfall2.exe 的游戏根目录。
应用重复打开时会聚焦已有窗口，避免同一配置多实例同时写入。当前版本沿用 fold.json 配置名称，保留已有用户设置。

国服、全球服与原版
北极星页面可选择 NorthstarCN 国服或 Northstar 全球服。每个客户端单独显示未安装、待切换、已启用或需修复。内置包或缓存不代表已安装。
未安装时先点击对应安装按钮。安装过程校验文件并显示进度，完成后再点击启动游戏。首次安装需展开与校验；两套客户端准备好后，通过同盘目录轮换切换核心文件，保留个人模组、皮肤与设置。同服再次启动避免重复展开。
游戏正在运行时不能切换或改写客户端。安装或更新期间改变游戏目录、profile 或渠道会停止提交并恢复事务。配置损坏或外部修改冲突会显示原因。
内置国服 1.17.7、全球服 1.31.13。较新的已识别国服在本机保留私有快照，不会直接降级。自动更新不会替未安装的渠道执行首次安装。
全球服内置包省略可选 Discord Rich Presence 插件；不影响核心客户端文件。用户从官方发布下载的完整更新原样安装。此项是发布许可整理，详见署名说明。
原版页面启动 EA 原版。北极星只有确认核心菜单成功加载后才显示启动成功；快速关闭游戏后会解除等待状态。平台交接尚未完成时保留必要等待时间，异常提供错误原因。
设置可开启“游戏启动后退出启动器”，确认本次游戏启动成功后退出 TFX。该选项默认关闭。

社区服务器
独立页面按纵向列表展示服务器，可切换国服与全球服、搜索、查看地图、玩法、人数和所需模组。列表与其他页面共用页面滚动区域。首页左下角显示所选网络公开服务器的在线人数。
数据加载、暂时不可用、旧缓存分别显示。退出相关页面或隐藏窗口会暂停无用刷新。列表仅供浏览，进入游戏后在游戏内选服加入。

我的模组与下载
支持名称、作者、说明搜索，以及添加时间、名称、启用状态排序。排序和语言选择使用应用内菜单。开关保存有状态反馈，失败时恢复实际状态，滚动位置与搜索内容保留。
“发现模组”入口位于“我的模组”内。目录和官方下载源为 https://thunderstore.io/c/northstar/ 。依赖先规划后下载，包校验全部通过才提交；可取消，失败保留或恢复既有内容。
包所有权按确切作者和包名识别，不按模糊名称删除用户模组。外部导入支持有效 mod.json 目录与 ZIP 包；DDS/VTF 皮肤、损坏包、不安全路径和核心组件伪装包会报错。
原生插件安装先在应用内确认。每个包自己的 LICENSE 和作者资料原样保留。核心模组开关由客户端准备阶段保护。

DDS 皮肤
支持 DDS 文件、文件夹与 ZIP 包。导入检查文件头、压缩格式、尺寸、资源布局与分辨率覆盖。误导入 VTF 包会清空上一次待安装包并提示，不会安装旧选择。
替换同枪皮肤时先清理旧皮肤覆盖范围；新包缺少的材质需要可靠原版资源才能补回。若原版已被其他工具改写且没有可靠备份，会提示选择原版资源或通过 Steam 验证，不能凭猜测生成原版数据。
安装前建立备份，写入后校验。游戏启动、目标被外部修改、路径异常或校验失败会停止提交或保留恢复记录。

VTF 皮肤
接受含兼容 materials / models 文件的文件夹和压缩包，包括 ZIP、7z、RAR；以包内文件为准。支持动态 VTF 及关联模型。无兼容文件、损坏包或错误格式会明确报错并清除旧选择。
DDS 与 VTF 的同枪替换由共同事务协调，处理旧材质和模型入口；不会用其他枪的备份覆盖当前枪。遇到未完成记录时按提示先恢复。

备份和启动保护
DDS / VTF 默认各显示最近五条记录，更多记录可展开。每条记录提供删除入口，仅允许删除已经结束且没有恢复依赖的历史记录；当前皮肤和未完成事务所需记录不可直接删除。
恢复顺序遵守安装依赖，先恢复较新的记录；跨格式恢复会同时处理两种资源。
“皮肤启动保护”位于偏好设置，对 DDS 与 VTF 生效。记录当前 setting.stream_memory 和 setting.mat_picmip，启动前恢复所记录值；确认游戏显示正常后可重新记录。它不锁定游戏内画质选项，记录值也不是所有皮肤通用的兼容保证。
保护开关立即保存；取消设置不撤销这项操作。即使关闭保护，未完成安装事务仍需恢复后才能启动。

界面和设置
十种主题均可预览；普通设置在成功写入后才保存并关闭，写入失败保持窗口与输入。取消撤销未保存预览。
支持简体中文、繁体中文、英语、德语和法语。首次中文系统选择对应中文，其他系统默认英语；保存的手动选择优先。
长按恢复默认需连续按住两秒，松开、移开、失焦或关闭窗口会取消。完成后立即保存默认偏好，保留游戏目录、缓存路径、已安装模组与皮肤。
窗口保留方形外边框，顶部空白可拖动、双击最大化或还原。内部使用磨砂玻璃与短时页面过渡；系统减少动态效果时遵从设置。
系统 DNS 工具只在用户明确操作并确认后修改网络，可能请求 Windows 管理员权限；平时不自动改变网络配置。

更新与反馈
关于中的“检查更新”读取本项目 GitHub 最新正式 Release，区分尚未发布、已是最新、可更新和网络失败。点击下载或版本页后打开官方链接，不静默替换运行中的程序。
提交问题时请注明 TFX 版本、客户端渠道、操作步骤和报错文字；附日志前自行检查个人路径等信息。
