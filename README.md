# TFX Launcher 1.0.0

TFX is a Windows x64 launcher for TITANFALL 2, NorthstarCN and Northstar. Author: HarryCao.

TFX 是面向 Windows x64 的《泰坦陨落 2》启动器，提供原版游戏启动、北极星国服与全球服管理、社区服务器浏览、模组管理，以及 DDS / VTF 皮肤安装与恢复。

项目 / Project: https://github.com/harrycaoguitar-hue/TFX_Launcher_forNorthStar

问题与建议 / Support: harrycaoguitar@gmail.com · https://github.com/harrycaoguitar-hue/TFX_Launcher_forNorthStar/issues

## 使用 / Getting started

从 Releases 下载 Windows x64 便携版并运行 TFX-Launcher-1.0.0.exe。需要已购买并安装的 TITANFALL 2 及正常可用的 Steam / EA 环境。自动识别失败时，选择包含 Titanfall2.exe 的游戏根目录。国服、全球服未安装时，先点击对应客户端的安装按钮；完成后启动游戏。

Download the Windows x64 portable EXE from Releases. A legitimate TITANFALL 2 installation and a working Steam / EA setup are required. Select the folder containing Titanfall2.exe if automatic detection cannot find it. Install the selected Northstar client before launching it. Client installation and game launch are separate actions.

Supports Simplified Chinese, Traditional Chinese, English, German and French. First use follows Chinese system variants; all other systems default to English. Saved language choices take priority. The five-language preference menu belongs to the app.

## 功能 / Features

- 独立客户端安装状态、国服与全球服切换、原版启动及失败原因反馈。
- 实时社区服务器列表；模组搜索、添加时间 / 名称 / 启用状态排序；Thunderstore 模组与依赖安装。
- DDS 与 VTF 皮肤格式检查、同枪覆盖协调、安装备份、恢复及受保护的备份删除。
- 十种磨砂主题、页面动画、减少动态效果支持、长按恢复默认、启动后退出选项。
- GitHub 正式版检查更新。检查只读取公开版本信息，用户选择后打开官方下载页。

See USER_GUIDE.txt for installation, backups, switching, settings and recovery. See BUILD.md for source builds and tests.
