# TFX interface gallery

These images show the actual English **TFX 1.0.3** frontend. The production HTML, CSS, fonts and JavaScript were rendered in Chromium; the screens were not redrawn. Each image was captured at 3200 × 2000 (a 1600 × 1000 viewport at 2× device scale), resized once to 1600 × 1000 with Lanczos resampling and encoded as WebP at quality 90. Rounded corners come from the production window stylesheet.

| File | View |
|---|---|
| `play.webp` | Northstar launch screen and network selector |
| `mods.webp` | Installed Mod cards, search and sorting |
| `servers.webp` | Public server directory layout |
| `dds.webp` | Unified installer with a DDS package and installation progress |
| `vtf.webp` | The same installer with a VTF package and installation progress |
| `arsenal.webp` | Weapon catalogue, current skin and selectable historical skins |
| `preferences.webp` | Preferences, themes and language controls |

Numbered Mods, skins, servers, the example game path, player counts, versions and installation states are controlled demonstration data. They do not represent a user's installed content or live server availability. IPC was replaced by an inert fixture; HTTP(S) requests were blocked. No real package was imported and no game files were read or written. The screenshot fixture intentionally demonstrates successful client / resource checks and an installation in progress; it does not measure installation performance.
