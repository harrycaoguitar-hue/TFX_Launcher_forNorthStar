# TFX interface gallery

These images show the actual English TFX 1.0.2 frontend, rendered from the same source included in this release. The interface layout, fonts and styles have not been redrawn. Images are resized once from a 2× capture and encoded as WebP.

Numbered mods, skins, servers, the sample game path, player counts and installation states come from an isolated demonstration fixture. They do not represent installed user content or live server availability. The fixture blocks external requests and does not write to an actual game installation.
